# サンドボックス受入チェックリスト (買い切り移行)

本番 (sk_live) に切り替える前に、サンドボックスで全項目を通す。
「合格条件」を1つでも満たさないときは、本番切替に進まない。

見る場所は3つある。Stripe ダッシュボード (決済が起きたか)、
Firestore の users/{uid}/private/entitlements (付与されたか)、
アプリ画面 (利用者から見えるか)。3つが食い違っていないことが本体の合格条件。

## 0. 前提 (ここが済んでいないと以降は無意味)

- [ ] サンドボックスの Webhook に charge.refunded と charge.dispute.closed を追加した
- [ ] config/pricing.js の CHECKOUT_MODE が payment、PACK_PRICE_YEN 3980、PRICE_MAX 1980
- [ ] 上記がデプロイ済み (本番サイトの /config/pricing.js を開いて目視)
- [ ] 画面の表記が買い切りになっている (科目カードに「(買い切り)」、マイページに契約管理ボタンが無い)
- [ ] テスト用アカウントで一度ログアウト・ログインし直した (古い entitlements が残らないように)

## 1. 単品の購入

テストカード 4242 4242 4242 4242、期限は未来、CVC は任意の3桁。

- [ ] 科目カードの「購入」から Checkout が開く。金額が画面の表示と一致する
- [ ] 支払い完了後、数十秒以内にアプリ画面が「購入済み」に変わる
- [ ] Stripe: Payments に1件、status は Succeeded。Subscriptions には何も増えない
- [ ] Firestore: subjects.{科目id} に purchaseType: one_time、status: active、
      paymentIntentId と checkoutSessionId が入っている
- [ ] アプリ: その科目で20問を超えて出題できる (無料枠の頭打ちが消えている)

合格条件: Subscriptions が増えないこと。増えていたら mode が payment になっていない。

## 2. プレミアムパックの購入

- [ ] 別のテストアカウントで、パックを購入する
- [ ] Firestore: pack: true と packPurchase が入る
- [ ] アプリ: 全科目が無制限になる。マイページに解約系のボタンが出ない

## 3. 二重購入のガード

- [ ] 1 で買った科目の「購入」を、もう一度押す (ボタンが出ていなければ合格)
- [ ] マイページから同じ科目の購入を試すと、
      「こちらはすでに購入済みです」で決済画面が作られない
- [ ] パックを持っているアカウントで単品を買おうとすると、同じく止まる

合格条件: 同じものに二度払えないこと。

## 4. 返金で付与が消える (ここが今回の本題)

- [ ] Stripe の Payments から、1 で作った支払いを全額返金する
- [ ] 数十秒後、Firestore の subjects.{科目id} が消えている
- [ ] アプリを再読み込みすると「購入済み」が消え、無料枠の表示に戻る
- [ ] Cloud Logging に Webhook handler error が出ていない

合格条件: 返金した相手が使えなくなること。ここが通らないと本番に出せない。

## 5. 一部返金では消えない

- [ ] 別の購入を1件作り、一部だけ返金する
- [ ] Firestore の付与がそのまま残っている
- [ ] アプリでも引き続き使える

合格条件: 一部返金で付与を消さないこと (全額返金だけが取り消しの合図)。

## 6. 返金したあとに買い直す

- [ ] 4 で返金した科目を、同じアカウントでもう一度購入する
- [ ] 付与が復活する
- [ ] その後、古い返金イベントを Stripe から再送しても、新しい付与が消えない
      (Stripe の Webhook 一覧から該当イベントの再送を実行して確認)

合格条件: 支払い1件に一致する枠だけが消えること。

## 7. チャージバック (任意・時間がかかる)

- [ ] テストカード 4000 0000 0000 0259 で購入し、異議申立てを発生させる
- [ ] 異議が確定して負けた (lost) ときだけ付与が消える
- [ ] 申立て中は使えたまま

## 8. 単品を持っている人がパックを買う

買い切りには解約も相殺も無いので、単品のあとにパックを買うと先に払った分は沈む。
差額課金はしない。警告だけ出す(社長判断 2026-10-04)。節2はまっさらな
アカウントで買うので、この経路は通らない。

- [ ] 1 で単品を買ったアカウントで、そのままパックの購入を押す
- [ ] 確認ダイアログが出る。件数・支払い済みの額・合計額の3つが文面に入っている
- [ ] 支払い済みの額が、1 で実際に払った額と一致している
- [ ] キャンセルで Checkout が開かない(Stripe 側に何も作られない)
- [ ] OK で Checkout が開き、パックの 3980 が出る
- [ ] 支払い後、pack が true になり、subjects の単品の記録が消えていない
- [ ] パックだけ全額返金すると pack が false に戻り、単品はそのまま使える

合格条件: 警告が出ること、キャンセルで止まること、単品の記録が消えないこと。

## 9. 失敗したときの見方

- Cloud Logging で Webhook handler error: の行を見る。Stripe 側の Webhook 一覧でも
  レスポンスコードが見える (200 以外が並んでいたら署名かコードの問題)
- 署名エラーなら STRIPE_WEBHOOK_SECRET が今のエンドポイントのものと違う
- イベントが一件も届いていないなら、送信対象イベントの選択漏れ
