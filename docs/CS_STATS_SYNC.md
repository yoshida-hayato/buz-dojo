# CS運用メモ：タグ「成績・同期」

お問い合わせや問題指摘で、次のような申告を扱うときの運用メモです。

- 段位が下がった
- 正答率が消えた
- 端末ごとに数が違う

admin UIの大規模改修はしません。クローズ時のメモ欄や社内メモに、タグと理由を手書きで残します。

**タグ:** `成績・同期`

**クローズ理由（2択）**

1. **端末キャッシュ起因（案内済）**  
   古いJSや画面の残存。ページの再読み込み（端末キャッシュ更新）を案内し、解消または手順提示済みでクローズ。

2. **再同期／端末差（案内済）**  
   ログイン中のクラウド未反映や端末間の一時差。マイページ再表示による再同期を案内し、手順提示済み（または実データ修復完了）でクローズ。

切り分け順: 再読み込み →（ログイン中）マイページ再表示。

画面の信頼ラインも同趣旨です。「常に最新」などの過大保証はしません。データ汚染や段位ロジックの疑いは、シカ（プラットフォーム本部・信頼性）へエスカレーションします。
