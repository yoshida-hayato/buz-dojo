# Search Console の登録手順 (社長の手が要る1件)

書いた日: 2026-10-25 (06:48便)

## なぜこれが最優先に近いか

売上は0件。その手前に「そもそも誰も来ていない」が在る。決済の経路は
10/17 から 10/24 でかなり固めたので、いま効くのは流入の側である。

流入のために着地頁を4枚作った (guides の4枚)。sitemap には18本が載り、
GA4 の札は 10/25 の時点でその18頁すべてに入っている。だが「検索エンジンが
この頁を索引しているか」は GA4 では分からない。GA4 は来た人を数える道具で、
来ていない理由は見えない。

社員の検索道具では測れないことも、10/11 に実測で確定している。あの道具は
米国向けで、サイト指定の検索も日本語の実務的な検索語も、我々も競合も
1本も返さない。だから「索引されているか」の一次情報は Search Console だけで、
それは社長のアカウントにしか無い。

この問いは 10/09 から 10/13 にかけて社員が繰り返し出していたが、
返事が無いまま引き継ぎメモの一覧から落ちた。落ちている間に着地頁が
4枚になった。索引されていなければ、4枚とも誰の目にも触れていない。

## 手順 (3手。どれも無料で、デプロイも DNS も要らない)

1. Search Console を開き、プロパティを追加する。種類は URL プレフィックス
   を選ぶ。ドメイン プロパティは DNS のレコードを足せる必要があり、
   Firebase Hosting の既定ドメインでは使えない。値は本番のトップページの
   URL を、末尾のスラッシュまで入れて貼る。

2. 所有権の確認は Google アナリティクス を選ぶ。GA4 の札がトップページに
   入っているので、これで通る。ファイルを置く必要もデプロイも要らない。
   GA4 の編集権限があるアカウントで入ること。

3. 通ったら sitemap を送る。パスはサイトの根の下の sitemap.xml である。
   そのあと URL 検査で、トップと guides の4枚について
   インデックス登録をリクエストする (1日の上限が在る)。

2 が通らないときだけ、確認用の HTML ファイルを公開ディレクトリに置いて
デプロイする。Firebase Hosting は完全一致の静的ファイルを rewrites より
先に返すので、全パスを index.html に送る規則が在っても確認ファイルは返る。
robots.txt と sitemap.xml が実際にその形で返っている (本番で実測済み)。

## 登録すると分かること / 分からないこと

分かる:

- 索引されている頁の数と、除外された頁とその理由
- 検索での表示回数・クリック数・平均の順位
- どの検索語で出ているか

分からない:

- 売上。Search Console は購入を見ない
- 索引されることの保証。sitemap を送ってもインデックス登録は保証されないと
  主催者が明記している。被リンクが1本も無い状態でも発見自体は可能だが、
  これも無保証である

## 調べた事実 (06:48便。一次情報に当たった)

- Firebase Hosting の既定ドメインは Public Suffix List に登録されている
  (2019年5月のコミットで追加)。だからブラウザ上は、各サブドメインが
  独立した登録可能ドメインとして扱われる。ただし検索の順位評価でも
  完全に独立に扱われるという一次情報は見つからなかった。ここは未確認
- 「この既定ドメインだから索引されない」という記述は、検索エンジンの
  公式文書にも Firebase の公式文書にも無い。仕様上の根拠は無い
- 実証寄りの報告は2件だけ見つかった。1件は未掲載の事例だが、原因は
  SPA のクライアント描画 (描画前の HTML に中身が無い) とされており、
  ドメインは原因ではない。もう1件は無料サブドメインのホスト全般への
  言及で、この既定ドメインを名指ししていない
- 新しい内容が索引されるまでの目安は、数時間から数週間

最後の点は我々に当てはまる。guides の4枚のうち3枚は1週間以上前からあり、
4枚目は 10/25 に出た。だから「まだ時間が経っていないから」では
説明が付かない頁が、すでに3枚ある。

## 返事の形

「登録した」か「登録していない」の一言でよい。

登録したなら、索引済みの頁の数を1つだけ教えてほしい。0 なのか 3 なのか 18
なのかで、社員の次の一手が変わる。0 なら着地頁をもう1枚作っても誰も
見ないので、作らない。18 なら中身と検索語の勝負になる。
