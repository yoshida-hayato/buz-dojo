根拠: `FREE_ENTRY_DONT_BUY.md`（買わなくていい無料入口）。  
用途: お問い合わせ・inbox返信のコピペ用。短い定型のみ。造語禁止。  
Hosting・UI直書きはしない（UI文案は別チケット）。

部長会議第3回・採用チャレンジ（2026-09-14）。司会: イルカ（コーポレート・事業企画／室長）／担当: イヌ（カスタマーサクセス・部長／お客様相談）。

料金の単一ソースは `config/pricing.js`（100問以下は単品¥0／全日無料枠20問）。価格の断定は避け、案内時は現行料金を確認する。

**タグ:** `無料入口・買わなくていい`

公開前科目（入門など enabled:false）を「もう使えます」と言わない。

## 1. 操作を覚えたい／何を買えばいいか

件名例: 課金の相談・どの科目から・パックは必要か

```
操作を覚えたいだけなら、いまは買わなくて大丈夫です。

メールなら「Outlook」、会議・チャネルなら「Teams」が単品無料です。まずはそこからお試しください。

キー操作だけなら「ショートカット」もあります。問題数が多いので、先に無料枠（本日20問）で試してからで十分です。
```

---

## 2. オントロジーを勧められた／買おうとしている（操作学習者）

件名例: オントロジーは必要か・AIを学びたい（操作目的のとき）

```
オントロジーは、知識の置き方や設計の判断を学ぶ科目です。メールや会議の操作練習とは別物です。

操作ミスを減らしたいだけなら、単品もパックも急がなくて大丈夫です。Outlook／Teamsの無料科目から始めてください。

「最新のAIニュース」やプロンプト集ではありません。設計の判断を続けて学びたい方向けです。
```

---

## 3. 全部入りパックはお得か

```
プレミアムパックは、公開中のすべての科目を制限なく使えるプランです。

やりたいことが操作だけなら、パックより無料の単品からで大丈夫です。まだ無料枠20問を試していない場合は、先にそちらをおすすめします。
```

---

## 4. 生産管理・検定対策が本命

```
検定や現場の生産管理が本命なら、その科目を先にどうぞ。無料枠もあります。

操作や設計判断の科目をまとめて買う必要はありません。目的に合う科目からで大丈夫です。
```

---

## 5. まだ無料枠を試していない

```
まずは無料枠（本日20問）で雰囲気を見てからで大丈夫です。

100問以下の単品は無料の科目もあります（Outlook・Teamsなど）。合うかどうか確認してからの課金で問題ありません。
```

---

## 6. オントロジー関心だが基礎が早い／迷っている

件名例: オントロジー入門はあるか・基礎の前に何から

```
オントロジーは設計の判断を学ぶ科目です。操作学習だけが目的なら急がなくて大丈夫です。

用語の地図から入りたい場合は、公開後の「オントロジー入門」（無料帯想定）を先に案内します。現時点で未公開の科目は「もう使えます」とは言えません。

有料のオントロジー基礎は、クラス・関係・制約など知識の置き方を続けて学びたい方向けです。
```

## クローズ理由（メモ欄用・短文）

1. **無料入口案内済** — Outlook／Teams／無料枠を先に案内。課金急かしなし。
2. **本命切り分け済** — 操作 vs 設計判断 vs 検定を切り分け、不要な購入を止められた。
3. **未公開科目は約束せず** — 入門等は公開後案内。過大保証なし。

## 使ってよい言い方（短句）

- 操作なら Outlook と Teams は単品無料です。まずはそこからで大丈夫です
- オントロジーは設計の判断用です。メールや会議の使い方とは別物です
- プレミアムパックは全科目が制限なし。操作だけなら無料の単品からで大丈夫です
- いまは買わなくていい、で足りるケースが多いです

## 避けたい言い方

- 全部買った方がお得です（ニーズ無視）
- 最新のAIが学べます（過大・科目と不一致）
- 「深度トラック」「Teams協働」など社内造語
- 操作学習者にオントロジー単品／パックを急かすこと
- 未公開科目を使える前提で案内すること
