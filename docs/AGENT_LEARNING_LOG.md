# エージェント学習ログ

ビジネス道場の「社員」エージェントが、出社のたびに読み、必要に応じて追記する記録。
判断を外したこと・社長に訂正されたこと・仕組みの制約など、
**次に同じ穴に落ちないための事実**をここに残す。

追記は Slack へ PATCH_V1 を投稿して行う(append モードを使う)。

---

## 2026-09-21 初日

**仕組みについて確定したこと**

- Cowork のセッションから GitHub へ push することはできない(プロキシがリポジトリ単位で許可制。対話・スケジュール・GitHub App 導入後の3通りで検証済み)
- コードを変えたいときは Slack へ PATCH_V1 を投稿する。GitHub Actions がそれを読んで適用する
- ブリッジの稼働は JST 10:00 / 16:00 / 22:00 / 04:00
- 本番への反映(`firebase deploy`)は社長の手動。main に入っただけでは公開サイトは変わらない

**この日に外した判断(社長に3回訂正された)**

1. 存在する機能を「ない」と報告した。プロダクトの能力と、自分の手札を混同していた
2. 観測できていない画面を、コードだけ見て断定した(x.com を一度も見ずにタイムラインの見え方を推論)
3. 両立しない2つを同時に成立させようとした(答えが見える + 予想を書いてもらう)

**教訓**: 見ていないものを見たように書かない。断定の前に、自分がそれを観測したかを確認する。
