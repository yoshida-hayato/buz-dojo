## まず自分の数字 (config/pricing.js から)

- SAP は 4,951問。買い切り 1,980円。1問あたり 0.40円
- 1,980円 は単品の上限 (PRICE MAX) である。式は3,000問で頭打ちになるので、
  4,951問でも3,000問でも請求額は同じ
- 有料7科目の合計は 7,361問。うち SAP が 4,951問で 67パーセント
- 内訳: sap 4951 / biz-career 823 / biz-pm-planning 694 / windows-shortcuts 341 /
  biz-pm-operation 295 / excel-functions 150 / ai-ontology-core 107
- パックは 3,980円。SAP 単品との差は 2,000円。SAP が目当ての人には、
  残り6科目 (2,410問) が 2,000円に見える

## 市場の大きさ

- SAP認定コンサルタント 国内 17,773人 (2020年8月末、SAPジャパン公表、週刊BCN)。
  2018年初頭は約9,000人。2年半で倍増した。2026年の現在値は未確認
- 国内のSAP導入企業は約1,300社 (電通総研のSAPユーザー企業意識調査2023年度版の
  母集団)。有効回答262社のうち ECC 6.0 が190社、S/4HANA が72社
- 比較: ビジキャリ生産管理2級の申請者は1期 1,161人 (令和7年度後期)
- 追い風がある。SAP ERP (ECC) の標準保守が2027年に切れるため、
  S/4HANA への移行案件と、それを担う人の需要が2026年から2027年に集中する。
  ベンダー各社がこれを「2027年問題」と呼んで記事を出している

## ここから言えること (推測。観測ではない)

1. 1,980円 という上限は、SAP の市場を見て置いた数字ではない。
   問題数3,000で頭打ちになる式の、たまたまの出口である
2. 外の相場 (100問で2,980円) と並べると、4,951問で1,980円は桁が違って安い。
   ただし相手は資格試験に的を絞った商品で、こちらは実務寄りである。
   同じ棚に並ぶかは確かめていない
3. 生産管理に注いだ便の数とSAPに注いだ便の数が、市場の大きさと逆になっている。
   生産管理は1期千人台で無料の競合が居り、SAPは万人の桁で無料の競合が居ない

## 小さく試すなら

値段をいじる前に、計測を読むこと。funnel は 10/17 に5段まで入った。

- SAP の paywall view が何件立つか。0 なら値段の話ではなく流入の話である
- paywall view が立って begin checkout が立たないなら、1,980円 が高いのではなく、
  4,951問の価値が画面で伝わっていない可能性がある (問題数は画面に出ている)
- 値段を動かすのは、この2つを読んでからでよい。式を変えると7科目全部が動く
