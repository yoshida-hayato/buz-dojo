### 共通して見られた型

1. 6件すべて、価格をファーストビューに出していない。出るのは割引だけ
2. 主ボタンは1種類。1画面に「無料で学習」と「購入する」が並ぶ形は1件も無い
3. 社会的証明を H1 の直後に置くのは2件 (Progate と Studyplus)。資格系は
   人数より合格実績の形を取る
4. 講座一覧をトップに直接並べるのは2件。残りは下層へ送る
5. 「まず解いてみる」型のボタンは6件中0件。過去問サイトすら置いていない
